Chapter 06 · Sequential Models

Hidden Markov Models

Understanding how artificial intelligence estimates hidden states from observations, predicts future conditions, and discovers the most probable sequence of events.

AI FUNDAMENTALS · PREPARED BY ABILASHIM MIRAS · PROFESSOR GULZHAN USKENBAYEVA

01. What Are Hidden Markov Models?

A Hidden Markov Model (HMM) is a statistical model used to understand systems where the actual condition is hidden, but we can observe indirect measurements.

For example, a machine may be Healthy, Degrading, or Faulty. We cannot directly observe its internal condition, but we can measure temperature, vibration, and noise.

Hidden States (X)

The actual conditions of a system that cannot be directly observed.

Observations (E)

Measurements or signals generated by the hidden states.

Time Sequence

Observations arrive over time and help us estimate the hidden state.

Hidden State
Healthy / Faulty
→
Observation
Temperature / Vibration

The Markov Assumption

The future state depends only on the current state, not the entire previous history.

P(Xₜ₊₁ | Xₜ, Xₜ₋₁, ...) = P(Xₜ₊₁ | Xₜ)
Key idea: The current state summarizes the relevant information from the past.

02. The Three Components of an HMM

An HMM is represented by three main components:

λ = (π, T, O)

π — Initial Probabilities

Describes the probability distribution over hidden states at the beginning of the sequence.

π = [0.80, 0.20]

T — Transition Matrix

Describes the probability of moving from one hidden state to another.

Tᵢⱼ = P(Xₜ = j | Xₜ₋₁ = i)

O — Emission Matrix

Describes the probability of observing a measurement given the current hidden state.

Oⱼ(e) = P(Eₜ = e | Xₜ = j)

Example: Machine Health Model

Our model has two possible states: Healthy (H) and Faulty (F).

Current state Next: Healthy Next: Faulty
Healthy 0.90 0.10
Faulty 0.20 0.80
T = [[0.90, 0.10], [0.20, 0.80]]

Emission probabilities:

Hidden state Normal reading High reading
Healthy 0.80 0.20
Faulty 0.30 0.70
Each row of the transition matrix sums to 1. The emission probabilities for each hidden state also sum to 1.

03. Filtering — What Is Happening Now?

Filtering estimates the current hidden state using all observations received so far.

P(Xₜ | e₁:ₜ)

The Predict–Correct–Normalize Cycle

1. Predict

Use the transition matrix to estimate the next state.

b' = b × T

2. Correct

Multiply the predicted belief by the observation likelihood.

b'' = b' × O(e)

3. Normalize

Make the probabilities sum to 1.

b = b'' / Σb''

04. Prediction — What Will Happen Next?

Prediction estimates future hidden states without receiving additional observations.

pₜ₊ₖ = pₜ × Tᵏ

Here, Tᵏ represents the transition matrix multiplied by itself k times.

Example: If a machine is currently estimated to be 80% Healthy and 20% Faulty, the transition matrix can be used to estimate its condition one or more steps into the future.

Filtering vs. Prediction

Filtering Prediction
Uses new observations. Does not use new observations.
Estimates the current state. Estimates a future state.
Useful for real-time monitoring. Useful for forecasting and maintenance planning.

05. Smoothing — What Was Happening Then?

Smoothing estimates a past hidden state using both past and future observations.

P(Xₖ | e₁:ₜ), where k < T

Unlike filtering, smoothing has access to the complete observation sequence. This can improve the estimate of an earlier hidden state.

Forward–Backward Algorithm

Forward
Past evidence
+
Backward
Future evidence
→
Smoothed
Estimate
P(Xₖ | e₁:ₜ) ∝ forwardₖ × backwardₖ
Smoothing is especially useful when analyzing historical sensor data after the complete sequence has been collected.

06. Viterbi Algorithm — Which Path Is Best?

The Viterbi algorithm finds the single most probable sequence of hidden states that could have generated the observations.

X*₁:ₜ = argmax P(X₁:ₜ | e₁:ₜ)

Filtering sums the probabilities of possible paths. Viterbi instead selects the highest-probability path using the MAX operator.

Viterbi Recurrence

δₜ(j) = Oⱼ(eₜ) × maxᵢ [δₜ₋₁(i) × Tᵢⱼ]
  • δ stores the best probability of a path ending in each state.
  • MAX selects the best previous state.
  • Backpointers remember which previous state was selected.
  • Backtracking reconstructs the most probable sequence.
Important distinction: Choosing the most probable state independently at every time step does not necessarily produce the globally most probable sequence.

Filtering vs. Viterbi

Filtering Viterbi
Uses SUM (Σ). Uses MAX.
Finds probability of each current state. Finds one best complete state sequence.
Real-time state estimation. Speech recognition and sequence decoding.

07. The Four Fundamental Inference Tasks

Task Main Question Algorithm Operator
Filtering What is happening now? Forward SUM
Prediction What will happen next? Matrix power Matrix multiplication
Smoothing What happened in the past? Forward–Backward SUM
Decoding Which complete path is most likely? Viterbi MAX

08. Python Implementation

We can implement HMM filtering using NumPy. The example below processes two consecutive High sensor observations.

import numpy as np # Transition matrix T = np.array([ [0.90, 0.10], [0.20, 0.80] ]) # Emission probabilities O = { "Normal": np.array([0.80, 0.30]), "High": np.array([0.20, 0.70]) } # Initial belief belief = np.array([0.80, 0.20]) observations = ["High", "High"] for t, obs in enumerate(observations): # Predict after the first observation if t > 0: belief = belief @ T # Correct using the observation belief = belief * O[obs] # Normalize belief = belief / belief.sum() print( f"Time {t+1}: " f"Healthy={belief[0]:.3f}, " f"Faulty={belief[1]:.3f}" )

Expected Output

Time 1: Healthy=0.533, Faulty=0.467 Time 2: Healthy=0.277, Faulty=0.723

Viterbi Decoding with hmmlearn

The hmmlearn library provides tools for working with Hidden Markov Models.

import numpy as np from hmmlearn.hmm import CategoricalHMM model = CategoricalHMM( n_components=2, init_params="", params="" ) model.startprob_ = np.array([0.80, 0.20]) model.transmat_ = np.array([ [0.90, 0.10], [0.20, 0.80] ]) model.emissionprob_ = np.array([ [0.80, 0.20], [0.30, 0.70] ]) # 0 = Normal, 1 = High observations = np.array([[1], [1], [0]]) best_path = model.predict(observations) print("Most probable state sequence:", best_path)
Install the libraries before running the examples:

pip install numpy hmmlearn

In this model, state 0 means Healthy and state 1 means Faulty.
