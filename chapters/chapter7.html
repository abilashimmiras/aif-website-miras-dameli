01. Foundations of Rationality

A rational agent chooses an action that maximizes expected performance based on the evidence and information available before making the decision.

Rationality

Choosing the best action based on available evidence and expected outcomes.

Omniscience

Knowing the actual outcome of every possible decision in advance.

Evidence

Information available to an agent when it makes a decision.

Important: Rationality does not guarantee success. A decision can be rational even when the eventual outcome is unfavorable. Decisions should be judged using the information available at the time, not only by hindsight.

The Rational Action Rule

An agent compares possible actions and selects the one with the highest expected utility.

a* = argmaxₐ E[U | a, e]

Here, a is a candidate action, e is the available evidence, and U represents the utility of an outcome.

02. Expected Utility & Maximum Expected Utility

Expected Utility (EU) combines the probability of each possible outcome with the utility associated with that outcome.

EU(a) = Σᵢ P(oᵢ | a) × U(oᵢ)

The Maximum Expected Utility (MEU) rule selects the action with the highest expected utility.

a* = argmaxₐ EU(a)

Worked Example: Project Selection

03. Decisions Under Uncertainty

Bayesian Belief Updating

Bayesian reasoning updates the probability of a hypothesis after new evidence becomes available.

P(H | D) = P(D | H)P(H) / P(D)

A prior probability represents the initial belief. The posterior probability represents the updated belief after observing evidence.

Cost-Optimal Decision Threshold

In practical decision problems, the best action depends not only on probability but also on the economic costs of each outcome.

p* = Cmaint / Cfailure

In this simplified maintenance model, preventive maintenance is selected when the predicted failure probability exceeds the cost-optimal threshold.

Worked Example: Machine Maintenance

04. Machine Learning Paradigms

Machine Learning (ML) allows systems to learn patterns from data and improve their predictions or decisions without being explicitly programmed for every situation.

Supervised Learning

Learns from labeled examples containing inputs and correct targets. Examples: regression and classification.

Unsupervised Learning

Finds hidden structures and patterns in data without labeled targets. Example: clustering.

Reinforcement Learning

05. Classical Machine Learning Algorithms

Linear Regression

Linear Regression predicts a continuous numerical value using a linear relationship between input features and a target.

ŷ = wx + b
MSE = (1/n) Σᵢ (yᵢ - ŷᵢ)²

The model learns parameters w and b by minimizing Mean Squared Error (MSE).

Logistic Regression

Logistic Regression is commonly used for binary classification. It transforms a linear score into a probability.

z = wᵀx + b
σ(z) = 1 / (1 + e⁻ᶻ)

The sigmoid function produces an output between 0 and 1, which can be interpreted as a predicted class probability.

Decision Trees

A Decision Tree makes predictions using a sequence of feature-based questions and branches.

Temperature high?
No → Continue
Yes → Check vibration
Normal → Monitor
High → Inspect machine

Random Forests

A Random Forest combines predictions from multiple decision trees. It uses bootstrap samples and feature subsetting to create diversity among trees and reduce variance.

Random Forest = Combined predictions of multiple trees

K-Means Clustering

K-Means is an unsupervised algorithm that groups similar data points into K clusters.

  1. Choose the number of clusters K.
  2. Initialize K centroids.
  3. Assign each point to its nearest centroid.
  4. Recalculate the centroid of each cluster.
  5. Repeat until assignments or centroids stabilize.
J = Σₖ Σₓ∈Cₖ ||x - μₖ||²
Feature scaling is important for distance-based algorithms such as K-Means. Otherwise, features with larger numerical scales can dominate the distance calculation.

06. Model Evaluation

Model evaluation measures how well a machine-learning model performs on data that was not used to train it.

Confusion Matrix

Predicted Positive Predicted Negative
Actually Positive True Positive (TP) False Negative (FN)
Actually Negative False Positive (FP) True Negative (TN)

Important Evaluation Metrics

Accuracy

(TP + TN) / N

Fraction of all predictions that are correct.

Precision

TP / (TP + FP)

How many predicted positives are actually positive.

Recall

TP / (TP + FN)

How many actual positives the model identifies.

F1 = 2 × (Precision × Recall) / (Precision + Recall)

Why High Accuracy Is Not Always Enough

Imagine a dataset where only 2% of machines experience failure. A model that always predicts "No Failure" can achieve 98% accuracy, while identifying none of the actual failures.

In imbalanced classification problems, precision, recall, F1-score, and probability calibration can provide more useful information than accuracy alone.

07. Rational Machine Learning Integration

08. Python Implementation

Cost-Optimal Maintenance Pipeline

This example trains a Logistic Regression classifier, estimates failure probabilities, and applies a cost-based threshold.

import numpy as np from sklearn.pipeline import make_pipeline from sklearn.preprocessing import StandardScaler from sklearn.linear_model import LogisticRegression # 1. Create and train the model model = make_pipeline( StandardScaler(), LogisticRegression() ) model.fit(X_train, y_train) # 2. Estimate failure probabilities p_failure = model.predict_proba(X_test)[:, 1] # 3. Define economic costs c_maint = 2000 c_failure = 10000 # 4. Calculate the optimal threshold optimal_threshold = c_maint / c_failure # 5. Select rational actions actions = np.where( p_failure >= optimal_threshold, "Maintain", "Continue" ) print("Threshold:", optimal_threshold) print(actions)
