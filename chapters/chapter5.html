01 · Foundations

Why Probability Matters in AI

Artificial Intelligence systems often work with incomplete information, uncertain environments, and noisy sensor data. Probability provides a mathematical way to represent uncertainty and quantify how strongly an event is believed to occur.

0

An impossible event.

0.5

An event with a 50% probability.

1

An event that is certain.

Random Variables

A random variable represents an uncertain quantity or outcome.

For example, a machine's temperature can be represented as:

T ∈ {Normal, High}

The probabilities of all mutually exclusive and exhaustive outcomes must sum to 1.

Σ P(X = x) = 1
02 · Probability Rules

Joint, Marginal & Conditional Probability

Joint Probability

Joint probability measures the chance that two events happen together.

P(A,B) = P(A ∩ B)

Marginal Probability

Marginalization removes variables that are not needed by summing over their possible values.

P(A) = Σb P(A,b)

Conditional Probability

Conditional probability describes the probability of event A given that event B has occurred.

P(A|B) = P(A,B) / P(B)

Product Rule

P(A,B) = P(A|B) × P(B)

The chain rule extends this idea to multiple random variables.

P(A,B,C) = P(A|B,C)P(B|C)P(C)
03 · Bayesian Reasoning

Bayes' Theorem

Bayes' theorem allows us to update an initial belief using new evidence. It is especially useful when an AI system needs to estimate the probability of a hidden cause based on an observed result.

P(Cause|Evidence) = [P(Evidence|Cause) × P(Cause)] / P(Evidence)
Prior

Initial belief before observing new evidence.

Likelihood

Probability of observing the evidence if the cause is true.

Evidence

Overall probability of the observed result.

Posterior

Updated belief after considering the evidence.

Interactive Example: Machine Fault Detection

Suppose a factory has 1,000 machines. Only 5% have a fault. An alarm detects 90% of faulty machines, but it can also produce false alarms.

P(Fault | Alarm) = 32.14%
Important lesson: A detector with 90% sensitivity does not mean that an alarm indicates a 90% chance of a fault. The prior probability and false alarm rate also matter.

Base Rate Fallacy

The base rate fallacy occurs when people overlook how common or rare an event is before interpreting new evidence.

Even an accurate detector can produce many false alarms when the underlying event is rare.

04 · Independence

Conditional Independence

Two variables X and Y are conditionally independent given Z when knowing Z makes additional knowledge of X unhelpful for predicting Y, and vice versa.

P(X,Y|Z) = P(X|Z)P(Y|Z)

Explaining Away

Consider two possible causes of an alarm: a burglary and an earthquake.

Burglary
Earthquake
↘
↙
Alarm

Before observing the alarm, burglary and earthquake may be independent. After observing the alarm, evidence for one cause can reduce the probability of the other cause.

Example: If an earthquake is confirmed, a burglary becomes a less likely explanation for the same alarm. This phenomenon is called explaining away.
05 · Bayesian Networks

What Is a Bayesian Network?

A Bayesian Network is a probabilistic graphical model represented by a Directed Acyclic Graph (DAG).

Nodes

Represent random variables.

Directed Edges

Represent direct probabilistic dependencies.

DAG

A directed graph with no directed cycles.

CPT

A Conditional Probability Table for each node given its parents.

Example: Fire, Smoke and Alarm

Fire
→
Smoke
→
Alarm

In this example:

  • Fire can cause smoke.
  • Smoke can trigger an alarm.
  • Each node has a probability distribution conditioned on its parent nodes.

Conditional Probability Tables

A CPT stores the probability of a variable for each possible combination of its parent values. Root nodes have no parents and therefore store prior probabilities.

Network Factorization

The full joint probability distribution can be represented as a product of local conditional distributions.

P(X₁,...,Xₙ) = ∏i=1n P(Xᵢ | Parents(Xᵢ))
06 · Exact Inference

Inference in Bayesian Networks

Inference means calculating the probability of a query variable when some evidence is already known.

P(Q|E) = P(Q,E) / P(E)

Variables are often grouped into:

  • Query (Q): The variable whose probability we want to calculate.
  • Evidence (E): Variables with observed values.
  • Hidden (H): Variables that are not observed and must be summed out.

Enumeration

Enumeration explicitly considers all possible assignments of hidden variables and sums their contributions.

Time complexity: O(dⁿ)

It is straightforward but becomes expensive as the network grows.

Variable Elimination

Variable Elimination improves efficiency by combining probability factors and summing out hidden variables as early as possible. Intermediate calculations are reused rather than repeated.

Key distinction: Both enumeration and variable elimination are exact inference methods. Variable elimination can be much more efficient when the network has a favorable structure and low treewidth.
07 · Approximate Inference

Sampling Methods

For large networks, computing exact probabilities can be expensive. Sampling methods estimate probabilities using generated samples.

Prior Sampling

Generates samples from the Bayesian Network by following the graph from parent nodes to child nodes.

Rejection Sampling

Generates prior samples and rejects those that do not match the observed evidence.

Limitation: If evidence is rare, most samples may be rejected, wasting computation.

Likelihood Weighting

Fixes evidence variables to their observed values instead of rejecting samples. Each sample receives a weight based on the likelihood of the evidence given its parents.

Gibbs Sampling

A Markov Chain Monte Carlo (MCMC) method that repeatedly resamples hidden variables while keeping evidence fixed. Each hidden variable is sampled conditioned on its Markov blanket.

08 · Python Implementation

Variable Elimination: Fire → Smoke → Alarm

The following example calculates the probability of fire given that the alarm is on.

p_fire = {
    True: 0.02,
    False: 0.98
}

p_smoke = {
    True: {True: 0.90, False: 0.10},
    False: {True: 0.05, False: 0.95}
}

p_alarm = {
    True: 0.95,
    False: 0.01
}

# Eliminate the hidden Smoke variable
factor_phi = {}

for fire in [True, False]:
    factor_phi[fire] = sum(
        p_smoke[fire][smoke] * p_alarm[smoke]
        for smoke in [True, False]
    )

# Calculate unnormalized scores
scores = {
    f: p_fire[f] * factor_phi[f]
    for f in p_fire
}

# Normalize
posterior_fire = (
    scores[True] / sum(scores.values())
)

print(f"P(Fire | Alarm=ON) = {posterior_fire:.2%}")
Expected output: Approximately 23.46%.

Likelihood Weighting

import random

random.seed(42)
yes_weight = 0.0
total_weight = 0.0

for _ in range(100000):
    fire = random.random() < 0.02

    smoke = random.random() < (
        0.90 if fire else 0.05
    )

    # Evidence: Alarm = True
    weight = 0.95 if smoke else 0.01

    total_weight += weight

    if fire:
        yes_weight += weight

print(yes_weight / total_weight)

This sampling approach estimates the same posterior probability. Its result may vary slightly depending on the samples generated.

10 · Summary

Key Takeaways

  • Probability allows AI systems to reason under uncertainty.
  • Joint, marginal, and conditional probability describe relationships between events.
  • Bayes' theorem updates beliefs using new evidence.
  • Conditional independence simplifies probabilistic reasoning.
  • Bayesian Networks represent dependencies using DAGs and CPTs.
  • Enumeration and Variable Elimination perform exact inference.
  • Sampling methods approximate probabilities in complex networks.
Central idea: Bayesian reasoning enables intelligent systems to update their beliefs when new information becomes available.
