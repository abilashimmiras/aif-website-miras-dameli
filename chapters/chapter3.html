01 · FOUNDATIONS

Foundations of Adversarial Search

Adversarial search is used when multiple decision-makers interact, and each player's actions influence the possible outcomes of the game.

⚔

Competition

Players have competing objectives and try to choose actions that improve their own outcomes.

◎

Strategic Decisions

The value of a move depends on the possible responses of other players.

♟

Game Trees

A tree represents possible moves, resulting states, and eventual game outcomes.

Core difference

In single-agent search, the agent controls the actions being considered. In adversarial search, the agent must also account for an opponent's strategic responses.

02 · GAME FORMULATION

Types of Games

Games can be classified according to how outcomes are determined and how information is shared.

Deterministic

The next state is completely determined by the current state and selected action.

Stochastic

Random events, such as dice rolls, influence the next state.

Two-player / Multiplayer

Games can involve two participants or multiple decision-makers.

Zero-sum

One player's gain corresponds to an equal loss for the opponent.

General-sum

Players can have different interests, including outcomes where both benefit.

Perfect / Imperfect Information

Perfect-information games expose the full game state. Imperfect-information games contain hidden information.

Two-Player Zero-Sum Game Model

A formal game can be described using these components.

States (S)

The set of all possible game configurations.

Initial State (s₀)

The starting configuration of the game.

Players

MAX tries to maximize utility; MIN tries to minimize it.

Actions (A)

The legal moves available to the current player.

Transition Function

Maps a state and action to the resulting state.

Terminal Utility

Assigns a numerical value to a finished game.

03 · MINIMAX

The Minimax Algorithm

Minimax chooses the best move while assuming that the opponent also plays optimally.

MAX PLAYER

Maximize Utility

Selects the action leading to the highest available value.

V(s) = max V(s')
MIN PLAYER

Minimize Utility

Selects the action leading to the lowest available value.

V(s) = min V(s')
MINIMAX RECURRENCE
V(s) = max / min V(s')

Terminal states receive their utility values. MAX and MIN nodes propagate values upward using maximum and minimum operations.

04 · SEARCH OPTIMIZATION

Alpha-Beta Pruning

Alpha-Beta Pruning improves Minimax by skipping branches that cannot influence the final decision.

α

Alpha (α)

The highest value MAX can guarantee so far along the current search path.

MAXIMUM LOWER BOUND
β

Beta (β)

The lowest value MIN can guarantee so far along the current search path.

MINIMUM UPPER BOUND
✂

Pruning

Stop evaluating remaining children when the current branch cannot improve the decision.

α ≥ β
PRUNING CONDITION
α ≥ β

Once alpha becomes greater than or equal to beta, the remaining children of the current node can be skipped.

Does pruning change the answer?

No. Alpha-Beta Pruning produces the same optimal decision as Minimax. It simply avoids unnecessary evaluations.

Computational Complexity

Standard Minimax O(bᵐ)
Optimal Alpha-Beta O(bᵐ/²)
Space Complexity O(bm)
Key factor Move ordering

Here, b is the branching factor and m is the maximum search depth. The improved time complexity assumes ideal move ordering.

05 · RESOURCE LIMITS

Depth-Limited Search & Evaluation

Large game trees cannot always be explored completely. Depth limits allow an agent to make decisions using estimates of non-terminal states.

Depth Limit

Search stops after reaching a predefined maximum depth.

Evaluation Function

Estimates how favorable a non-terminal game state is for a player.

Horizon Effect

An important future event may remain just beyond the search depth and therefore be missed by the evaluation.

DEPTH-LIMITED EVALUATION
V(s) = Eval(s)

At the depth cutoff, the evaluation function estimates the value of the current state.

Chess example

An evaluation function might combine material, mobility, and spatial control into a weighted score. The result estimates which player has the advantage.

06 · STOCHASTIC GAMES

Expectimax Search

When random events affect the game, Expectimax uses expected utility rather than assuming an opponent always chooses the worst possible outcome.

MAX Nodes

Select the action with the highest expected utility.

Chance Nodes

Calculate a probability-weighted average of possible outcomes.

Random Events

Model dice rolls, random behavior, and other uncertain outcomes.

EXPECTED UTILITY
V(s) = Σ P(s') × V(s')

Each possible successor contributes its value multiplied by its probability.

Minimax assumes a strategic opponent who chooses the worst outcome for MAX. Expectimax models probabilistic outcomes using their expected values.

PYTHON IMPLEMENTATION

Game Tree Algorithms in Python

Explore the programming patterns used to implement adversarial search.

1. Depth-Limited Alpha-Beta Search

The recursive function evaluates states while updating alpha and beta bounds. 

import math

def alpha_beta(state, depth, alpha, beta, maximizing):

    if depth == 0 or state.is_terminal():
        return state.evaluate()

    if maximizing:
        value = -math.inf

        for child in state.successors():

            value = max(
                value,
                alpha_beta(
                    child, depth - 1,
                    alpha, beta, False
                )
            )

            alpha = max(alpha, value)

            if alpha >= beta:
                break

        return value

    else:
        value = math.inf

        for child in state.successors():

            value = min(
                value,
                alpha_beta(
                    child, depth - 1,
                    alpha, beta, True
                )
            )

            beta = min(beta, value)

            if beta <= alpha:
                break

        return value
Key concepts:
  • Recursion explores child states.
  • Alpha tracks MAX's best guaranteed value.
  • Beta tracks MIN's best guaranteed value.
  • The break statement stops unnecessary exploration.

2. Expectimax Evaluation

A chance node calculates the weighted sum of possible successor values. 

def exp_value(state):

    if state.is_terminal():
        return state.utility()

    total_value = 0.0

    for child, prob in state.get_stochastic_successors():

        total_value += prob * value(child)

    return total_value
Key concept: Each successor contributes according to its probability of occurring.
CHAPTER SUMMARY

Key Takeaways

  • Adversarial search models competing decision-makers.
  • MAX maximizes utility while MIN minimizes it.
  • Minimax assumes optimal play from both players.
  • Alpha-Beta Pruning skips irrelevant branches without changing the result.
  • Alpha and beta represent search bounds.
  • Move ordering strongly influences pruning efficiency.
  • Depth-limited search uses evaluation functions.
  • The horizon effect can hide important future events.
  • Expectimax handles stochastic outcomes using probabilities.
  • The choice of algorithm should match the game environment.
