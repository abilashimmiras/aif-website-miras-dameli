01 · FUNDAMENTALS

Foundations of Local Search

Local search is an optimization technique that improves a candidate solution by exploring its neighboring states.

◈

Candidate State

A complete possible solution to an optimization problem.

⇄

Neighbor Definition

Defines how one candidate solution can be changed into another nearby solution.

Σ

Objective Function

Measures the quality of a candidate solution through maximization or minimization.

Core idea

Unlike classical search, local search focuses on finding a good final configuration rather than remembering every step taken to reach it.

LOCAL SEARCH MEMORY
O(1) or O(K)

Local search retains only a small number of candidate states instead of maintaining a large search frontier.

03 · GREEDY OPTIMIZATION

Hill Climbing

Hill Climbing is a simple local search algorithm that repeatedly moves to a better neighboring state.

Three Main Failure Modes

Hill Climbing can become trapped because it only considers nearby neighboring states.

01. Local Maximum

A peak that is higher than its immediate neighbors but lower than the global maximum.

02. Plateau

A flat area where neighboring states have the same evaluation value.

03. Ridge

A narrow ascending region where reaching a better state may require combined moves.

04 · ADVANCED STRATEGIES

Escaping Local Traps

Several strategies improve local search by introducing randomness, multiple candidates, or controlled exploration.

Advantage

02

Simulated Annealing

PROBABILISTIC SEARCH

Inspired by the physical process of annealing in metallurgy. It sometimes accepts worse solutions to escape local maxima.

ACCEPTANCE PROBABILITY
P = eΔE / T

ΔE represents the change in objective value and T represents temperature.

High Temperature

More exploration. Worse moves have a higher probability of acceptance.

Low Temperature

More exploitation. The algorithm increasingly favors improving moves.

Cooling schedule: Temperature gradually decreases over time.
T ← T × α
Here, α is a cooling factor between 0 and 1.
03

Local Beam Search

MULTIPLE CANDIDATE STATES

Maintains K candidate states simultaneously. It generates their successors and selects the best K states overall.

Important distinction

Unlike K independent Hill Climbing runs, Local Beam Search shares information by selecting the best successors across all current candidates.

06 · CONTINUOUS OPTIMIZATION

Gradient Descent

Continuous optimization works with real-valued variables instead of a finite collection of discrete states.

Continuous Domains

Variables can take real-number values belonging to Rⁿ.

Random Perturbations

Small random changes can be applied to candidate variable values.

Gradient Methods

Calculus-based techniques use derivatives to optimize differentiable functions.

GRADIENT DESCENT UPDATE RULE
x ← x − α∇f(x)

Variables are updated in the opposite direction of the gradient to locate a minimum.

x Current parameter values
α Learning rate / step size
∇f(x) Gradient of the function
Goal Minimize the objective function
Key concept

The gradient points in the direction of steepest increase. Gradient Descent moves in the opposite direction to reduce the function value.

07 · PYTHON IMPLEMENTATION

Local Search in Python

Let's examine how the main optimization strategies can be implemented in Python.

1. Hill Climbing — 1D Landscape

The algorithm checks neighboring positions and moves to the one with the highest value. 

def hill_climbing(values, start):
    current = start

    while True:
        neighbors = []

        if current > 0:
            neighbors.append(current - 1)

        if current < len(values) - 1:
            neighbors.append(current + 1)

        best = current

        for n in neighbors:
            if values[n] > values[best]:
                best = n

        if best == current:
            break

        current = best

    return current
Explanation: The function examines adjacent positions, chooses the best improvement, and stops when no better neighbor exists.

2. Simulated Annealing — Acceptance Rule

This function determines whether a new candidate solution should be accepted. 

import math
import random

def accept_check(delta_e, temperature):

    if delta_e > 0:
        return True

    return random.random() < math.exp(
        delta_e / temperature
    )
Explanation: Improving moves are accepted automatically. Worse moves may also be accepted depending on temperature and their objective difference.
REAL-WORLD APPLICATIONS

Where Is Local Search Used?

Optimization algorithms solve problems where finding a good configuration is more important than finding a particular path.

♛

N-Queens Problem

Place N queens on a chessboard while minimizing the number of attacking queen pairs.

⌖

Travelling Salesperson

Find a short route visiting every city, using techniques such as 2-opt edge swaps.

⌘

Parameter Optimization

Adjust continuous model parameters to minimize an objective or loss function.

CHAPTER SUMMARY

Key Takeaways

  • Local Search optimizes complete configurations rather than paths.
  • It requires relatively little memory.
  • Hill Climbing moves toward better neighboring states.
  • Local maxima, plateaus, and ridges can trap greedy search.
  • Random Restarts explore different initial states.
  • Simulated Annealing can accept worse moves using temperature.
  • Local Beam Search maintains K candidate states.
  • Genetic Algorithms use selection, crossover, and mutation.
  • Gradient Descent updates variables using the negative gradient.
  • N-Queens and TSP are important local search applications.
