01 · FUNDAMENTALS

Search Problem Formulation

Before an AI system can find a solution, it needs to understand the problem.

◈

State Space

An abstract representation of an environment containing the information necessary for planning.

◎

Start State

The initial situation or position from which the search process begins.

⇄

Successor Function

Defines available actions, their resulting states, and the associated step costs.

✓

Goal Test

Checks whether the current state satisfies the desired goal conditions.

Σ

Path Cost

The total cost accumulated while moving from the initial state to a particular state.

Two different ways of representing the exploration of possible solutions.

03 · UNINFORMED SEARCH

Uninformed Search Algorithms

These algorithms explore the search space without using estimates of how close a state is to the goal.

01

Breadth-First Search (BFS)

FIFO QUEUE

Explores the shallowest nodes first, level by level.

Data structureFIFO Queue
ExpansionShallowest first
OptimalityYes, equal step costs
MemoryHigh
BFS finds the shortest path in terms of the number of edges when all step costs are equal.
02

Depth-First Search (DFS)

LIFO STACK

Explores the deepest available node before backtracking.

Data structureLIFO Stack
ExpansionDeepest first
OptimalityNot guaranteed
MemoryLow
DFS can be memory efficient, but it does not guarantee the shortest or least-cost path.
03

Iterative Deepening Search

REPEATED DEPTH-LIMITED SEARCH

Repeatedly performs depth-limited DFS, increasing the depth limit each time.

StrategyIncreasing depth
MemoryLow
AdvantageCombines DFS and BFS benefits
04

Uniform Cost Search (UCS)

PRIORITY QUEUE

Expands the node with the lowest accumulated path cost.

Data structureMin-Heap
ExpansionLowest g(n)
CompletenessYes, under standard positive-cost assumptions
OptimalityYes, non-negative costs
UCS considers the cost already spent, but does not estimate the remaining distance to the goal.
04 · INFORMED SEARCH

Understanding A* Search

A* combines the actual cost of a path with an estimate of the remaining cost.

A* EVALUATION FUNCTION
f(n) = g(n) + h(n)

The estimated total cost of a solution path through node n.

↙

g(n)

The exact path cost from the start node to the current node.

PAST COST
↗

h(n)

The estimated remaining cost from the current node to the goal.

FUTURE COST
Σ

f(n)

The sum of actual path cost and estimated future cost.

05 · HEURISTICS

Heuristic Admissibility

A heuristic helps an algorithm estimate how far a state is from the goal.

ADMISSIBILITY CONDITION
0 ≤ h(n) ≤ h*(n)

An admissible heuristic never overestimates the true minimum remaining cost to reach the goal.

Why is this important?

An admissible heuristic guarantees that A* tree search finds an optimal solution under the standard search assumptions.

What if the heuristic overestimates?

An inadmissible heuristic may cause A* to select a path that appears promising but is not actually optimal.

07 · COMPARISON

A* Search vs. Uniform Cost Search

Both algorithms use path costs, but A* also considers a heuristic.

Feature UCS A*
Evaluation g(n) g(n) + h(n)
Past cost Yes Yes
Heuristic No Yes
Optimality Yes, with non-negative costs Yes, with suitable admissible heuristics and search conditions
Guidance Cost-based Cost and goal estimate
Key relationship

If h(n) = 0 for every node, A* behaves exactly like UCS. A useful admissible heuristic can reduce unnecessary node expansions while preserving optimality.

CHAPTER SUMMARY

Key Takeaways

  • Search problems consist of states, actions, costs, and goals.
  • BFS explores shallowest nodes first.
  • DFS explores deepest nodes first.
  • Iterative Deepening combines useful properties of BFS and DFS.
  • UCS expands nodes based on accumulated path cost.
  • A* combines actual cost and estimated future cost.
  • Admissible heuristics help A* find optimal solutions.
