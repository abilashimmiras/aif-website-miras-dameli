01. Foundations of Unsupervised Learning

Unsupervised Learning is a branch of Machine Learning that discovers patterns, relationships, and hidden structures in data without using predefined target labels.

Unlabeled Data

The dataset contains input features X but does not contain known target labels y.

Pattern Discovery

Algorithms identify similarities, groups, relationships, and unusual observations.

Exploration

Results are interpreted using internal metrics, visualization, stability checks, and domain knowledge.

Supervised vs. Unsupervised Learning

Main objective Predict known outcomes Discover hidden structures
Evaluation Accuracy, precision, recall Internal metrics and interpretation

02. K-Means Clustering

K-Means is a partition-based clustering algorithm that divides a dataset into K groups. Each group is represented by a centroid, which is the mean position of its assigned observations.

How K-Means Works

  1. Choose the number of clusters K.
  2. Initialize K centroids.
  3. Assign each data point to its nearest centroid.
  4. Calculate new centroids using the mean of assigned points.
  5. Repeat assignment and updating until the algorithm converges.

K-Means Objective Function

K-Means minimizes the Within-Cluster Sum of Squares (Inertia). It measures the squared distance between each data point and the centroid of its assigned cluster.

J = Σₖ₌₁ᴷ Σₓᵢ∈Cₖ ||xᵢ − μₖ||²

Where:

  • K = number of clusters.
  • Cₖ = the set of observations in cluster k.
  • xᵢ = an individual data point.
  • μₖ = centroid of cluster k.

Advantages and Limitations

AdvantagesLimitations
Simple and easy to understand. Requires choosing K in advance.
Computationally efficient. Sensitive to outliers.
Scales well to large datasets. Works best with roughly spherical clusters.
Useful for customer segmentation. Sensitive to feature scaling and initialization.

03. DBSCAN — Density-Based Clustering

DBSCAN (Density-Based Spatial Clustering of Applications with Noise) identifies clusters by finding regions with sufficiently high concentrations of data points.

Unlike K-Means, DBSCAN does not require the number of clusters to be specified in advance. It can also identify irregularly shaped clusters and observations considered noise.

Two Main Hyperparameters

ε (Epsilon)

Defines the radius of the neighborhood around a data point.

min_samples

Defines the minimum number of nearby observations required to form a dense region.

Noise

Observations that do not belong to a density-connected cluster are labeled -1.

Three Types of Points

Point TypeDefinition
Core Point Has at least min_samples observations in its ε-neighborhood, including itself.
Border Point Has fewer than min_samples nearby observations but lies within the neighborhood of a core point.
Noise Point Cannot be assigned to a cluster under the DBSCAN density rules.

DBSCAN vs. K-Means

Feature K-Means DBSCAN
Number of clusters Must specify K Discovered automatically
Cluster shape Generally spherical Arbitrary shapes
Outliers Sensitive to outliers Can identify noise
Main parameters K ε and min_samples

When Is DBSCAN Useful?

  • Geographical location analysis.
  • Identifying irregularly shaped data groups.
  • Discovering unusual observations.
  • Spatial and sensor data analysis.
Limitation: DBSCAN can struggle when clusters have very different densities. Its performance is also affected by high-dimensional data and feature scaling.

04. Evaluating Clustering Performance

Since unsupervised learning does not have predefined target labels, clustering algorithms are evaluated using internal measures of compactness and separation.

Elbow Method

The Elbow Method helps select an appropriate K for K-Means. It compares the number of clusters with the resulting inertia.

  1. Run K-Means with different values of K.
  2. Calculate inertia for each value.
  3. Plot K against inertia.
  4. Look for the point where the decrease becomes less significant.
Increasing K always reduces or maintains inertia. If K equals the number of observations, each observation can form its own cluster and inertia becomes zero. Therefore, the lowest inertia is not automatically the best model.

Silhouette Coefficient

The Silhouette Coefficient measures how well an observation fits into its own cluster compared with the nearest alternative cluster.

s(i) = [b(i) − a(i)] / max(a(i), b(i))
  • a(i) = average distance to observations in the same cluster.
  • b(i) = average distance to observations in the nearest alternative cluster.
  • s(i) = silhouette score for observation i.
ScoreInterpretation
Close to +1Well-separated and compact clustering.
Close to 0Observation lies near a cluster boundary.
Below 0Observation may be assigned to the wrong cluster.

05. Dimensionality Reduction

Dimensionality Reduction transforms data with many features into a smaller number of dimensions while attempting to preserve important information.

Why Reduce Dimensions?

Visualization

Converts complex datasets into 2D or 3D representations that humans can explore.

Efficiency

Reduces computational requirements and storage needs.

Noise Reduction

Can remove redundant or less informative dimensions.

The Curse of Dimensionality

As the number of dimensions increases, the volume of the feature space grows rapidly. Data points become increasingly sparse, and distance-based methods can become less reliable.

Feature Space Volume ∝ Lᵈ

Here, L represents the length of each dimension and d represents the number of dimensions.

Example: A dataset with 2 features is easier to visualize than a dataset with 500 features. Dimensionality reduction helps represent the complex dataset using fewer coordinates.

Linear vs. Nonlinear Methods

Linear MethodsNonlinear Methods
Preserve linear combinations of original features. Can represent complex nonlinear relationships.
Example: PCA. Examples: t-SNE and UMAP.
Generally computationally efficient. Often require more parameter tuning.

06. Principal Component Analysis (PCA)

Principal Component Analysis is a linear dimensionality reduction technique that transforms original features into a smaller set of orthogonal components.

PCA identifies directions of maximum variance in the dataset. These directions are called principal components.

How PCA Works

  1. Standardize the input features when their scales differ.
  2. Center the data by subtracting feature means.
  3. Calculate the covariance matrix.
  4. Find eigenvectors and eigenvalues.
  5. Sort components by descending eigenvalues.
  6. Select the desired number of components.
  7. Project the original data onto the selected components.

Covariance Matrix

Σ = (1 / (n − 1)) XcᵀXc

Where Xc is the centered data matrix and n is the number of observations.

Eigenvalue Decomposition

Σv = λv
  • v represents an eigenvector and a principal direction.
  • λ represents the eigenvalue and the variance along that direction.

Explained Variance Ratio

Explained Variance Ratio = λᵢ / Σⱼ λⱼ

The explained variance ratio indicates how much of the total variance is captured by each principal component.

Example: Retaining 95% Variance

Suppose the first components explain the following proportions of total variance:

PC150%
PC230%
PC315%
PC45%
50% + 30% + 15% = 95%
Selecting the first three principal components preserves 95% of the total variance in this example, reducing four dimensions to three.

Advantages and Limitations of PCA

AdvantagesLimitations
Fast and computationally efficient. Captures only linear relationships.
Reduces redundant features. Components may be difficult to interpret.
Helps visualize complex datasets. Sensitive to feature scaling and outliers.

07. Nonlinear Techniques: t-SNE & UMAP

Nonlinear dimensionality reduction techniques help represent complex data structures that cannot always be captured by linear methods such as PCA.

t-SNE (t-Distributed Stochastic Neighbor Embedding)

t-SNE is a nonlinear dimensionality reduction technique that converts similarities between high-dimensional observations into probabilities and attempts to preserve local neighborhoods in a low-dimensional representation.

Local Structure

Focuses on keeping nearby observations close together in the visualization.

Perplexity

Controls the effective neighborhood scale and influences the local structure being considered.

Visualization

Commonly used to visualize complex datasets in 2D or 3D.

Important t-SNE limitation: Distances between separate clusters should not be interpreted literally. Cluster sizes and global distances can be distorted.

UMAP (Uniform Manifold Approximation and Projection)

UMAP is a nonlinear dimensionality reduction technique based on manifold learning and graph theory.

It constructs a graph representing relationships between nearby observations and optimizes a low-dimensional representation of that structure.

n_neighbors

Controls the approximate local neighborhood size used to construct the graph.

min_dist

Controls how tightly observations can be packed together in the low-dimensional representation.

Performance

Often scales better than t-SNE on larger datasets and can preserve useful local and broader structure.

Comparison: PCA vs. t-SNE vs. UMAP

Feature PCA t-SNE UMAP
Method Linear Nonlinear Nonlinear
Main focus Maximum variance Local neighborhoods Local and broader structure
Common parameters n_components perplexity n_neighbors, min_dist
Speed Usually fast Often slower Often faster than t-SNE
Typical use Compression Visualization Visualization and exploration
t-SNE and UMAP are especially useful for exploring complex high-dimensional data. However, a 2D visualization should not automatically be treated as proof that the displayed clusters represent meaningful real-world categories.

08. Anomaly Detection

Anomaly Detection identifies observations that differ significantly from the general patterns of a dataset.

Anomalies may represent rare events, unusual combinations of features, measurement errors, or unexpected system behavior.

Types of Anomalies

Point Anomaly

An individual observation that is significantly different from the rest of the dataset.

Contextual Anomaly

An observation that is unusual in a specific context, such as a temperature reading for a particular season.

Collective Anomaly

A group or sequence of observations that is unusual when considered together.

Multivariate Anomalies

A multivariate anomaly occurs when a combination of features is unusual, even though each individual feature may appear normal when examined separately.

Example: A machine may have normal temperature and normal vibration individually. However, a particular combination of temperature and vibration may be unusual for its operating state.

Isolation Forest

Isolation Forest is an anomaly detection algorithm based on random partitioning of the feature space using decision trees.

The main idea is that unusual observations are easier to isolate than common observations. They generally require fewer random splits to become isolated.

How Isolation Forest Works

  1. Randomly select a feature.
  2. Randomly select a split value within that feature's range.
  3. Divide the observations into smaller groups.
  4. Repeat the process using multiple isolation trees.
  5. Calculate the average path length for each observation.
  6. Assign anomaly scores based on the isolation behavior.
s(x,n) = 2−E[h(x)] / c(n)

Where:

  • E[h(x)] = average path length of observation x.
  • c(n) = normalization factor based on sample size.
  • n = number of observations in the sample.
c(n) ≈ 2(ln(n−1) + 0.5772156649) − 2(n−1)/n

Interpreting Anomaly Scores

Score behaviorInterpretation
Close to 1 Strong indication of an anomaly.
Close to 0.5 Observation is relatively difficult to distinguish from normal data.
Below 0.5 Observation is more consistent with normal patterns.

Interactive: Understanding Isolation Forest

Shorter paths generally indicate more unusual observations.

Limitations of Anomaly Detection

  • An unusual observation is not automatically an error.
  • Rare but valid behavior may be flagged as anomalous.
  • Results depend on the dataset and selected parameters.
  • Domain knowledge is important when interpreting results.
Remember: Statistical anomaly does not necessarily mean system failure. An unusual observation may represent a rare but valid operating condition.

09. Python Implementation

Scikit-Learn provides practical implementations of clustering, dimensionality reduction, and anomaly detection algorithms.

Installing Required Libraries

pip install numpy pandas matplotlib scikit-learn

1. Feature Scaling

Feature scaling is especially important for distance-based and variance-based algorithms.

from sklearn.preprocessing import StandardScaler scaler = StandardScaler() X_scaled = scaler.fit_transform(X_raw)

2. K-Means Clustering

from sklearn.cluster import KMeans kmeans = KMeans( n_clusters=3, random_state=42, n_init=10 ) kmeans_labels = kmeans.fit_predict(X_scaled) print("Cluster labels:", kmeans_labels) print("Inertia:", kmeans.inertia_)

3. DBSCAN Clustering

from sklearn.cluster import DBSCAN dbscan = DBSCAN( eps=0.35, min_samples=5 ) dbscan_labels = dbscan.fit_predict(X_scaled) # -1 indicates noise print("DBSCAN labels:", dbscan_labels)

4. Principal Component Analysis

from sklearn.decomposition import PCA pca = PCA( n_components=0.95, random_state=42 ) X_pca = pca.fit_transform(X_scaled) print("Original dimensions:", X_scaled.shape[1]) print("Reduced dimensions:", X_pca.shape[1]) print( "Explained variance:", pca.explained_variance_ratio_.sum() )

5. t-SNE Visualization

from sklearn.manifold import TSNE tsne = TSNE( n_components=2, perplexity=30, learning_rate="auto", init="pca", random_state=42 ) X_tsne = tsne.fit_transform(X_scaled)
For t-SNE, the perplexity must be smaller than the number of observations. Its value should be selected with the dataset size and structure in mind.

6. UMAP Dimensionality Reduction

# Install separately: # pip install umap-learn import umap reducer = umap.UMAP( n_neighbors=15, min_dist=0.1, n_components=2, random_state=42 ) X_umap = reducer.fit_transform(X_scaled)

7. Isolation Forest

from sklearn.ensemble import IsolationForest iso = IsolationForest( n_estimators=200, contamination=0.05, random_state=42 ) anomaly_labels = iso.fit_predict(X_scaled) # 1 = Normal, -1 = Anomaly anomaly_scores = iso.decision_function(X_scaled) print("Labels:", anomaly_labels) print("Anomaly scores:", anomaly_scores)

Preventing Data Leakage with PCA

When PCA is used as preprocessing for supervised learning, it must be fitted only on the training portion of each cross-validation fold.

from sklearn.pipeline import make_pipeline from sklearn.preprocessing import StandardScaler from sklearn.decomposition import PCA from sklearn.linear_model import LogisticRegression pipeline = make_pipeline( StandardScaler(), PCA(n_components=0.95), LogisticRegression() ) pipeline.fit(X_train, y_train) predictions = pipeline.predict(X_test)
Using a Scikit-Learn Pipeline prevents the preprocessing steps from learning information from the test data during cross-validation.
