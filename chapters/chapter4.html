01 · Foundations

Sequential Decision-Making

In many AI problems, an action does not only affect the present. It also changes which situations and decisions become available in the future.

Sequential decision-making aims to maximize the expected long-term reward rather than choosing an action based only on its immediate result.

Planning vs. Classical Search

Classical Search

Finds a sequence of actions or a path from a starting state to a goal.

MDP Planning

Finds a policy that tells an agent which action to choose in each possible state.

02 · Mathematical Model

What Is a Markov Decision Process?

A Markov Decision Process (MDP) is a mathematical framework for modeling decision-making when actions can lead to uncertain outcomes.

M = (S, A, P, R, γ)
S — States

All possible situations the agent can be in.

A — Actions

Available choices the agent can make.

P — Transitions

Probability of reaching a new state after an action.

R — Rewards

Immediate feedback received after an action.

γ — Discount Factor

Controls how much future rewards matter.

The Markov Property

The current state contains all the relevant information needed to predict the next state. The entire history does not need to be stored separately.

P(St+1 | St, At, history) = P(St+1 | St, At)
Remember: The future depends on the current state and action, not on the full history, when the state satisfies the Markov property.
03 · Rewards & Values

Return and Value Functions

A reward is immediate feedback. A value function estimates how much total future reward an agent can expect.

Discounted Return

Gt = Rt+1 + γRt+2 + γ²Rt+3 + ...

Two Important Value Functions

State Value Vπ(s)

Expected return starting from state s and following policy π.

Action Value Qπ(s,a)

Expected return after taking action a in state s and following policy π afterward.

Bellman Expectation Equation

It expresses the value of a state as the expected immediate reward plus the discounted value of the next state.

Vπ(s) = Σa π(a|s) Σs′ P(s′|s,a) [R(s,a,s′) + γVπ(s′)]

Bellman Optimality Equations

These equations choose the action that produces the highest expected long-term return.

V*(s) = maxa Σs′ P(s′|s,a) [R(s,a,s′) + γV*(s′)]
Q*(s,a) = Σs′ P(s′|s,a) [R(s,a,s′) + γ maxa′ Q*(s′,a′)]
04 · Model-Based Planning

Planning with Known Models

When transition probabilities and rewards are known, an agent can calculate good decisions without learning them through trial and error.

Value Iteration

Repeatedly updates the value of every state using the Bellman optimality equation until the values become stable.

Vk+1(s) = maxa Σs′ P(s′|s,a) [R + γVk(s′)]

Policy Iteration

Alternates between two stages:

1. Policy Evaluation

Calculate the value of the current policy.

2. Policy Improvement

Choose better actions based on the calculated values.

05 · Reinforcement Learning

Model-Free Reinforcement Learning

In model-free RL, the agent does not know the transition probabilities or reward function in advance. It learns by interacting with the environment.

(St, At, Rt+1, St+1)

Exploration vs. Exploitation

Exploration

Trying new actions to discover potentially better rewards.

Exploitation

Choosing the action currently estimated to be the best.

The ε-greedy strategy balances these two approaches:

Random action: probability ε
Greedy action: probability 1 − ε

Monte Carlo Methods

Learn from complete episodes. After an episode ends, the agent uses the actual return to update its estimates. It does not bootstrap from an estimated next-state value.

Temporal-Difference Learning

Updates estimates after individual transitions. It learns before the full episode has ended by using its current estimate of the next state.

δt = Rt+1 + γV(St+1) − V(St)

This difference is called the TD error.

06 · Important Algorithms

Q-Learning vs. SARSA

Both algorithms learn action values through temporal-difference updates, but they use different estimates for the next action.

Q-Learning — Off-Policy

Uses the maximum estimated next-state action value, even if the agent actually takes a different exploratory action.

Q(s,a) ← Q(s,a) + α[r + γ maxa′ Q(s′,a′) − Q(s,a)]

SARSA — On-Policy

Uses the value of the actual next action selected by the current policy.

Q(s,a) ← Q(s,a) + α[r + γQ(s′,a′) − Q(s,a)]

07 · Deep Reinforcement Learning

Scaling Up: Deep RL

Traditional tabular methods store a separate value for each state-action pair. This becomes impractical when the state space is very large or continuous.

Deep Q-Networks (DQN)

DQN uses a deep neural network to approximate the action-value function:

Q(s,a; θ)
Experience Replay

Stores past transitions and samples random mini-batches to reduce correlation between consecutive experiences.

Target Network

A separate network with slowly updated parameters provides more stable learning targets.

Policy Gradients

Instead of learning only action values, policy-gradient methods directly optimize a parameterized policy:

πθ(a|s)

Actor-Critic Architecture

Actor

Selects actions according to the learned policy.

Critic

Evaluates states or actions and helps improve the Actor.

Real-World Applications

  • Industrial machine maintenance.
  • Battery energy management.
  • Robotics and autonomous systems.
  • Resource allocation and scheduling.
08 · Quick Reference

Understanding α, γ, and ε

ParameterMeaningEffect
α — Learning rateHow much new information changes an estimate.High α: faster updates, potentially noisier estimates.
γ — Discount factorImportance of future rewards.Near 0: immediate rewards matter more. Near 1: future rewards matter more.
ε — Exploration rateProbability of choosing a random action.High ε: more exploration. Low ε: more greedy choices.

10 · Summary

Key Takeaways

  • MDPs provide a framework for sequential decision-making under uncertainty.
  • A policy tells an agent which action to choose in each state.
  • Bellman equations connect immediate rewards with future values.
  • Value Iteration and Policy Iteration plan when the model is known.
  • Model-free RL learns from interaction with the environment.
  • Q-Learning is off-policy, while SARSA is on-policy.
  • DQN uses neural networks to handle larger state spaces.
Central idea: Reinforcement Learning allows an agent to improve its decisions by learning from the consequences of its actions.
